# data

全部数据。分「不可再生」与「可再生」两类 —— **这是本目录最重要的区分**。

| 子目录 | 不可再生？ | 说明 |
| --- | --- | --- |
| `raw/` | **是** | LeRobot 原片，下载来的。丢了要重下（且 express 已经下不到） |
| `label/` | **是** | 人类标注。丢了要重新标 |
| `llm_cache/` | **是** | LLM 生成的干扰项。**重跑会变成另一套题** |
| `vqa/` | 否 | 由上面三样 + `src/vqa/recipes` 确定性地产出，删了能重建 |

`llm_cache/` 单独放在 `vqa/` 外面，就是因为它不可再生 ——
放进去的话，哪天 `rm -rf data/vqa/` 重建，题目会悄悄换一套。
