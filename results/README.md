## run1 是什么

`SenseNova-SI-1.1-InternVL3-2B` × 六族 × 七题型，2026-08-19，
8 × RTX 4090，9,037 次调用，2.6 小时。

**这是一次测试性质的跑** —— 验证链路、拿第一个数据点。
**不是基准结果**：那需要跑完模型矩阵。

```
image_in_video  44.7%  +16.2σ      planning_2   28.0%   +2.4σ
understanding   40.9%  +13.7σ      left_right   26.2%   +1.4σ
                                   step_order   26.2%   +1.0σ
随机基线 25%                        planning     24.1%   −0.7σ
                                   time          0.0%   （tIoU@0.5）
```

结论与成因分析见 DEVLOG 的 **D-61**。两条要点：

- **planning 低于随机是系统性错误** —— 模型答的是「正在做什么」。
  当前动作出现在选项里时，选中它的条件概率 48%（随机 25%）。
- **time 归零不是那三个 bug 造成的**（bug 是真的，也都修了）。
  模型输出的是 [0,1] 归一化坐标；换算成秒后 tIoU 仍只有 0.002，
  **比「整段视频都报」这个退化基线的 0.101 还低** —— 它根本没在定位。

## 读之前

`image_in_video` 21.5%、`step_order` 上界 28.8%）。
